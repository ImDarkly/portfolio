- The server owns all game state — bag, racks, board, scores and turn order — and validates every placement.
- Clients send actions over WebSockets instead of changing game state directly; the server replies with authoritative state.
- Players drag tiles from their rack onto the board, and invalid placements return a specific error.
- No account needed: create a room, share the 6-character link, and play in the browser.
